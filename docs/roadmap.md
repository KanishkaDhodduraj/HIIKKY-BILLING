# HIIKKY Roadmap

## Project Status

HIIKKY is currently being developed as a Java-based subscription and billing management system using JDBC and MySQL.

* [x] Java application structure

* [x] JDBC integration
* [x] Layered architecture

## Phase 4 — Future Development

Potential future improvements may include:

* REST API development
* Web-based frontend
* Authentication and authorization
* Payment gateway integration
* Email notifications
* Cloud deployment

These items are planned possibilities and are not part of the current implementation.
