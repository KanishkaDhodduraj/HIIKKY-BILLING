# ADR-001: Use Java as the Programming Language

## Status

Accepted

## Date

2026-08-09

## Context

HIIKKY requires a programming language suitable for implementing business logic, object-oriented design, database connectivity, and maintainable application code.

## Decision

Java was selected as the primary programming language for HIIKKY.

## Reasons

* Strong support for Object-Oriented Programming
* Strong typing
* Large developer ecosystem
* Widely used for backend and enterprise applications
* Good support for database connectivity
* Helps build strong programming fundamentals

## Alternatives Considered

Other programming languages could be used to build the application.

However, Java was selected because the project is also intended to strengthen Java programming and backend development skills.

## Trade-offs

### Advantages

* Strong type safety
* Mature ecosystem
* Good object-oriented programming support
* Large community
* Suitable for larger applications

### Disadvantages

* More verbose than some modern languages
* Requires understanding of Java-specific concepts

## Result

HIIKKY is currently implemented using Java.
