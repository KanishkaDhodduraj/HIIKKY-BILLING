# HIIKKY - Courses Module

## Module Overview

The Courses Module was developed as part of the HIIKKY Subscription and Billing Management System.

The module was built for the Organization Owners portal and connected with the MySQL database using Java and JDBC.

The main focus was not only storing course details but also making the course structure billing-ready from the beginning.

## Features

The Courses Module supports:

- Course creation and management
- Course duration configuration
- Course fee configuration
- Full Payment
- Installment Payment
- Both Full Payment and Installments
- Installment scheduling
- Database integration

## Flexible Payment Configuration

One of the important features of the module is flexible payment configuration at the course level.

For example, if a course costs ₹30,000:

```text
Full Payment
₹30,000 at once

Installments
3 × ₹10,000

Both
The learner can choose between
Full Payment and Installments
```
