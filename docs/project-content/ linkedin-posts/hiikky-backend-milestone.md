# HIIKKY - Backend Development JDBC and CRUD

## Milestone Overview

A major backend milestone was completed during the development of HIIKKY.

The JDBC integration was successfully connected with the project, allowing the application to communicate with the MySQL database.

## Completed Modules

### Organization Module

The Organization module was implemented with full CRUD operations.

It provides the basic structure required for managing organization-related information within HIIKKY.

### Subscription Module

The Subscription module was also implemented with full CRUD operations.

This module forms an important part of the subscription lifecycle management system.

## Backend Architecture

The modules follow the same layered architecture:

Menu
  ↓
Service
  ↓
DAO
  ↓
MySQL
