# HIIKKY API Documentation

## Current Status

The current HIIKKY version is a Core Java + JDBC application and does not currently expose REST APIs.

Therefore, REST API documentation is not applicable to the current version.

## Future

If REST APIs are introduced in a future version, this directory will contain documentation for:

* Endpoints
* HTTP methods
* Request parameters
* Request bodies
* Response formats
* HTTP status codes
* Error responses
* Authentication requirements

API documentation will be added when REST APIs are actually implemented.
